

## What is Node.js?

Node.js is a JavaScript runtime environment that allows us to run
JavaScript outside the browser.

Browser
   ↓
JavaScript Engine
   ↓
JavaScript Code

With Node.js:

Computer/Server
   ↓
Node.js
   ↓
JavaScript Code
